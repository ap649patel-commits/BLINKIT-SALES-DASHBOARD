
# 🛒 Blinkit Sales Dashboard – Data Analysis Project

##  Project Overview

This project focuses on analyzing **Blinkit sales data** to understand sales performance, customer purchasing patterns, outlet performance, product-level trends, and other important business metrics.

An interactive **Blinkit Sales Dashboard** was created to transform raw sales data into meaningful insights using data analysis and visualization techniques.

The dashboard helps stakeholders quickly understand key performance indicators (KPIs), identify sales trends, and compare the performance of different outlets and product categories.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall sales performance.
* Identify the most important sales KPIs.
* Understand sales by product category.
* Compare outlet performance.
* Analyze sales based on outlet size and location.
* Study the relationship between product characteristics and sales.
* Identify high-performing and low-performing product categories.
* Create an interactive dashboard for easy business analysis.

---

## 📊 Key Performance Indicators (KPIs)

The dashboard focuses on the following KPIs:

* **Total Sales**
* **Average Sales**
* **Number of Items**
* **Average Rating**
* **Sales by Outlet**
* **Sales by Product Category**
* **Sales by Outlet Size**
* **Sales by Outlet Location Type**
* **Sales by Outlet Establishment Year**

## 🗂️ Dataset

The dataset contains information related to Blinkit outlets, products, and sales.

### Important Columns

| Column                    | Description                                  |
| ------------------------- | -------------------------------------------- |
| Item Identifier           | Unique identifier for each product           |
| Item Type                 | Category/type of product                     |
| Item Fat Content          | Fat classification of the product            |
| Item Weight               | Weight of the product                        |
| Item Visibility           | Visibility of the product in the outlet      |
| Item MRP                  | Maximum Retail Price                         |
| Outlet Identifier         | Unique identifier of the outlet              |
| Outlet Establishment Year | Year in which outlet was established         |
| Outlet Size               | Size of the outlet                           |
| Outlet Location Type      | Location classification of outlet            |
| Outlet Type               | Type of outlet                               |
| Item Outlet Sales         | Sales generated by the product at the outlet |
| Rating                    | Customer rating                              |

## 🚀 How to Use This Project

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd Blinkit-Sales-Dashboard
```

### 3. Install Required Python Libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### 4. Open the Jupyter Notebook

Run:

```bash
jupyter notebook
```

Then open the EDA notebook from the `Python` folder.

### 5. Power BI Dashboard

Open the `.pbix` file using **Microsoft Power BI Desktop** to explore the interactive dashboard.
